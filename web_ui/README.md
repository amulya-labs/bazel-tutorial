# Economic Dashboard UI

React + TypeScript frontend for the Economic Indicators Dashboard.

## 🌐 Live Demo

**[View Live Dashboard →](https://rrl-personal-projects.github.io/bazel-tutorial/app/)**

## Architecture

This React app supports two data fetching modes:

### 1. Static JSON (Default - GitHub Pages)

```
/data/summary.json           → Summary of all indicators
/data/series-CPIAUCSL.json   → CPI time series data
/data/series-UNRATE.json     → Unemployment time series data
...
```

The app first tries to fetch from `/data/*.json` static files. These files are:
- Generated by the Go fetch service using `--export-json` flag
- Committed to the repository
- Automatically updated daily by GitHub Actions
- Served directly by GitHub Pages (no backend needed)

### 2. REST API (Fallback - Local Development)

If static files are not found (404), the app falls back to calling:
```
/api/econ/summary          → Python FastAPI endpoint
/api/econ/series?code=...  → Series detail endpoint
```

This requires running the Python API server locally:
```bash
bazel run //py_api:server
```

## Development

### Install Dependencies

```bash
npm install
```

### Generate Static Data

```bash
# Fetch data and export to JSON
bazel run //go_fetch:refresh -- \
  --db="$(pwd)/../data/econ.db" \
  --export-json="$(pwd)/public/data"
```

### Run Dev Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
```

Output goes to `dist/` directory.

## Deployment

### GitHub Pages (Automated)

The `.github/workflows/update-dashboard.yaml` workflow:

1. Fetches latest FRED data using `bazel run //go_fetch:refresh`
2. Exports JSON files to `web_ui/public/data/`
3. Commits the JSON files to the repository
4. Builds the React app with `npm run build`
5. Deploys to GitHub Pages

**Required Secrets:**
- `FRED_API_KEY` - API key from https://fred.stlouisfed.org
- `WORKFLOW_PAT` - Personal Access Token with `repo` and `workflow` permissions
  (needed to bypass branch protection rules when committing data updates)

### Manual Deployment

```bash
# 1. Fetch and export data
bazel run //go_fetch:refresh -- \
  --db="$(pwd)/data/econ.db" \
  --export-json="$(pwd)/web_ui/public/data"

# 2. Build React app
cd web_ui
npm run build

# 3. Deploy dist/ to your hosting provider
```
